# 📌 Overview  
The **Inventory Analytics Platform** is a complete supply‑chain analytics solution built using:

- SQL Server (data warehouse + star schema)  
- Power BI (semantic model + dashboards)  
- ETL pipelines (staging → transformation → warehouse)  
- KPI‑driven insights across inventory, suppliers, manufacturing, and logistics  

This platform provides a **single source of truth** for operational decision‑making across the entire supply chain.

---

# 🎯 Purpose  
The goal of this project is to deliver:

- Real‑time inventory visibility  
- Supplier reliability and defect analysis  
- Manufacturing throughput and cost insights  
- Transportation performance and route efficiency  
- Executive‑level KPIs for strategic decision‑making  

It replaces fragmented spreadsheets with a unified, scalable analytics environment.
